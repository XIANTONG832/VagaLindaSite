# VagaLinda Site

Site estático em português brasileiro. `index.html` é a página de apresentação; `support.html` e `privacy.html` são as páginas de suporte e privacidade.

Antes de publicar: configurar um canal de contato real nas páginas de suporte e privacidade; revisar a política conforme os serviços usados; adicionar um link da App Store quando o aplicativo estiver disponível.
